# Obverser — 界面与功能设计

> 版本：v0.1（2026-08-22）
> 状态：交互逻辑定稿，不含技术实现细节
> 关联文档：[design.md](design.md)（技术架构）

## 1. 整体布局

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶部栏 frame（设置、宫格选择按钮等）                                 │
├──────────┬───────────────────────────────────────┬───────────────┤
│          │                                       │ 文件信息       │
│  文件     │                                       │ frame        │
│  frame   │            预览 frame（宫格区域）        │（右上）        │
│ （左）    │                                       ├───────────────┤
│          │                                       │ 格式转换       │
│          │                                       │ frame（右下）  │
│          ├───────────────────────────────────────┤               │
│          │ 功能 frame（预览下方一条，操作选中宫格）    │               │
└──────────┴───────────────────────────────────────┴───────────────┘
```

**frame 尺寸调整规则**（类似 Photoshop 面板，只能拖边框调大小，不能换位移动）：

| frame | 宽度 | 高度 |
|---|---|---|
| 文件 frame | 可调 | 不可调（贯穿左侧全高） |
| 预览 frame | 随窗口剩余空间自适应 | 自适应 |
| 文件信息 / 格式转换 frame | 可调（两者同宽，属于右栏） | 两者之间的分割线可上下拖动 |
| 功能 frame | 不可调（贯穿预览区底部） | 不可调 |

## 2. 顶部栏 frame

- **宫格选择按钮**：点击弹出类似 Word 插入表格的 m×n 悬停选择器，最大 **9×9**
- **设置入口**：图片放大模式等偏好设置；**记录管理**（预览历史/播放位置/滚动位置/3D 视角记录的查看与选择性删除，见 design.md §9）；**资源配额**（激活 3D 视口上限，默认 3；流媒体并发上限，默认 5——规则见 §4.7）
- 其余全局操作入口随版本迭代补充

## 3. 文件 frame（左侧）

### 3.1 面包屑 + 打开文件夹

- 顶部第一行显示当前根路径面包屑，如 `C: / Users / username / Desktop`
- **面包屑每段都可点击**，点击即"打开该文件夹"（将其设为当前根，下方刷新为其内容）
- 面包屑右侧是 **OpenFolder 按钮**，点击弹系统目录选择框，等价于"打开该文件夹"

### 3.2 打开文件夹的三种方式

1. OpenFolder 按钮（等价 VSCode 的 File → Open Folder）
2. 点击面包屑任意一段
3. 从应用外**拖动一个文件夹**到文件 frame，即打开该文件夹

### 3.3 内容列表规则

- 默认打开**桌面**文件夹
- 列表显示：**所有文件夹 + 所有可预览文件**；不可预览的文件不显示
- 即使某文件夹内没有任何可预览文件，文件夹本身仍然显示（不因此隐藏文件夹）
- 点击文件夹 = 展开/折叠（原地展开子内容，树形，类似 VSCode explorer）
- 点击文件 = 预览该文件（进入宫格，规则见 §4.3）
- 当前打开的根文件夹自身不显示为节点，其内容直接平铺在面包屑下方

### 3.4 打开的文件列表

- 文件 frame 内一个独立区块，显示**当前所有宫格中打开的文件的绝对路径**
- 用途：用户拖进宫格的文件可能不在当前打开的文件夹里，此列表是唯一能找到它们的地方
- 点击列表项 = 选中对应宫格（联动 §4.4 选中态）

## 4. 预览 frame（中央，宫格区域）

### 4.1 宫格布局

- 通过顶部栏宫格按钮选择 m×n 布局，最大 9×9，默认 1×1
- 宫格编号按**行优先**（从左到右、从上到下）：2×2 时为 `1 2 / 3 4`
- **缩小宫格规模时保留左上角子矩阵**：2×2（1 2 / 3 4）调整为 1×2 时保留第 1、3 格（第一列），被裁掉的宫格及其内容一并关闭
- 扩大宫格规模时，已有宫格保持原位，新增的是空白宫格

### 4.2 宫格的三种状态

| 状态 | 含义 |
|---|---|
| 空白宫格 | 无内容，等待预览 |
| 已填充 | 正在预览某文件 |
| 选中 | 已填充宫格中被选中的那个（高亮描边），功能/信息 frame 的操作对象；全局同时只有一个选中宫格 |

### 4.3 文件进入宫格的规则

| 操作 | 结果 |
|---|---|
| 单击文件 frame 中的文件 | 有空白宫格 → 进入**第一个空白宫格**；无空白宫格 → 覆盖**第 1 格**（左上角） |
| 拖拽文件到**某个具体宫格** | **强制覆盖**该宫格内容 |
| 拖拽来源 | 文件 frame、宫格之间、应用外（资源管理器等）均可 |
| 宫格间拖拽 | 把 A 宫格内容拖到 B 宫格 = 覆盖 B，A 变为空白宫格 |

### 4.4 选中与操作规则

- 轻点**未选中**的宫格 = 选中它（本次点击只改变选中态，不触发播放/暂停等任何内容操作）
- 轻点**已选中**的宫格 = 触发内容级操作（如视频/音频的播放/暂停切换）
- 每个宫格标题条提供两个操作：
  - **关闭**：该宫格变回空白宫格
  - **关闭其他宫格并单格展示**：关闭其余所有宫格，布局切换为 1×1，仅保留本宫格内容
- 全部宫格均为空白时，视为无选中宫格

### 4.5 选中宫格内的交互（按文件类型）

| 类型 | 滚轮 | 拖拽/点击 |
|---|---|---|
| 图片（含 SVG） | 以鼠标位置为中心缩放 | 按住拖动 = 平移 |
| 3D | 缩放（推近/拉远） | 拖动 = 旋转视角；滚轮+拖动足以覆盖全部视角，**不设快捷键** |
| 视频 | 调节音量 | 点击（已选中时）= 播放/暂停 |
| 音频 | 调节音量 | 点击（已选中时）= 播放/暂停 |
| PDF / 文本 / markdown | 滚动内容 | 普通文本交互 |
| Lottie/Rive 动效 | 滚动（如有超出内容） | 点击（已选中时）= 播放/暂停 |

### 4.6 全界面显示与全屏显示

仅**图片（含 SVG）和视频**支持，两种模式：

| 模式 | 行为 |
|---|---|
| **全界面显示** | 内容铺满整个应用窗口：隐藏文件/文件信息/格式转换/功能/顶部栏所有 frame，仅保留内容本身；仍为窗口状态（窗口边框、任务栏可见） |
| **全屏显示** | 操作系统级全屏：内容覆盖整块屏幕（含任务栏），在应用窗口所在的显示器上全屏 |

规则：

- 入口：功能 frame 中图片/视频按钮组的"全界面显示""全屏显示"按钮（§5）
- **Esc 退出**任一模式，退出后恢复原宫格布局、选中态、图片缩放位置、视频播放进度均保持不变
- 两种模式互斥：全界面中可再进全屏（视为切换到全屏），Esc 直接回到宫格视图（不逐层退）
- 模式中基础交互仍可用：图片滚轮缩放/拖动平移；视频播放/暂停、滚轮音量、进度操作；除 Esc 提示外不显示任何常驻 UI
- **底部悬浮功能条**（非常驻）：鼠标移到窗口最下方热区（约 48px）→ 浮出功能条，复用 §5 的按钮组并对**当前全屏格**操作（"全界面/全屏"进入按钮换成"退出"，等效 Esc）；移离底部后延时约 0.4s 自动隐藏。热区经 window mousemove 检测，不遮挡模式中内容的点击（如视频格内控制条）
- 模式仅作用于进入时的选中宫格；模式中不响应宫格切换、拖拽、文件单击等宫格级操作

### 4.7 资源配额：3D 视口与流媒体并发

| 配额 | 默认值 | 超额行为 |
|---|---|---|
| 激活 3D 视口数 | 3（顶部栏可调，硬上限 8） | 超出的 3D 宫格显示该模型**最后渲染帧的静态截图**；点击截图 = 激活该格视角，同时**最久未交互**的已激活视口自动降级为截图 |
| 同时播放的流媒体路数（视频+音频） | 5（顶部栏可调） | 第 6 路起播时，自动暂停**最久未交互**的一路；被暂停的宫格保留播放进度、显示海报帧，手动恢复播放时若仍超额则同样挤占 |

- 两项配额都在顶部栏设置中实时调整；调低时立即按"最久未交互"降级/暂停超额部分，调高时空出配额不自动恢复（需手动激活/播放）
- 配额只限制"激活/播放中"的数量，已加载但静态的宫格（图片、文本、暂停的媒体）不占配额

## 5. 功能 frame（预览区下方一条）

对**选中宫格**操作；无选中宫格时整体显示"未选择文件"并禁用所有按钮。按文件类型动态切换按钮组：

| 类型 | 功能按钮 |
|---|---|
| 图片（含 SVG） | 最佳显示（适应宫格）、1:1（实际像素）、缩放条、**全界面显示**、**全屏显示** |
| 音频 | 音量条、静音开关、播放速度、快进/快退、播放进度条 |
| 视频 | 音量条、静音开关、播放速度、快进/快退、**上一帧/下一帧**、播放进度条、最佳显示、1:1、缩放条、**全界面显示**、**全屏显示** |
| 3D | 重置视角、自动旋转开关、线框模式开关、（渲染）光照环境切换 |
| PDF/文本 | 页码跳转、缩放 |
| 压缩包（task2） | 无专属按钮；**双身份 zip 容器**（xlsx/xlsm/ods）出现"压缩包目录 / 表格预览"切换（只改当前格视角，不改文件与默认路由） |
| 通用（所有类型） | 在系统资源管理器中显示、复制文件路径 |

> "最佳显示/1:1/缩放条"三者联动：滚轮缩放或拖缩放条后自动脱离"最佳显示/1:1"模式；点按钮回到对应模式。

## 6. 文件信息 frame（右上）

显示**选中宫格**文件的信息；无选中时显示"未选择文件"。

| 类别 | 内容 |
|---|---|
| 通用 | 文件名、格式（扩展名+实际探测格式）、文件大小、修改时间、绝对路径（可复制） |
| 图片 | 分辨率、色彩空间、EXIF 摘要（相机/镜头/曝光参数，若有） |
| 视频 | 分辨率、时长、帧率、视频编码、音频编码、码率、HDR 标识 |
| 音频 | 时长、采样率、声道、编码、码率 |
| 3D | 顶点/面数、材质数、动画数、包围盒尺寸 |
| 动效 | 尺寸、帧率、时长（Lottie 的 w/h/fr/ip/op） |

## 7. 格式转换 frame（右下）

- 本版本**显示"暂不可用"**，仅占位（架构上已按 design.md §10 预留转换能力）
- 未来规划：对选中宫格文件选择目标格式、参数，提交转换任务，显示进度

## 8. 空态与边界汇总

| 场景 | 行为 |
|---|---|
| 启动 | 默认打开桌面文件夹，1×1 空白宫格 |
| 无选中宫格 | 功能 frame、文件信息 frame 显示"未选择文件"，格式转换 frame 恒为"暂不可用" |
| 宫格占满时单击文件 | 覆盖第 1 格 |
| 缩小宫格规模 | 保留左上角子矩阵，裁掉的宫格直接关闭 |
| 预览失败（解码错误/文件损坏） | 该宫格显示错误占位（文件名 + 失败原因），不崩溃、不影响其他宫格 |
| 文件被外部删除/移动 | 对应宫格显示"文件已不存在"；"打开的文件"列表中标记失效 |
